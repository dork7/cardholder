# Android end-to-end test report

Tested commit `035ab62` on the Pixel 9 Pro Android emulator with a debug build and synthetic test fixtures. Run started November 19, 2026.

67 of 128 catalogue cases have a recorded status. Pending cases have no verdict. The screenshot evidence and debug logs were kept in the local run.

| Pass | Fail | Blocked | Manual | Pending |
| ---: | ---: | ---: | ---: | ---: |
| 52 | 7 | 0 | 8 | 61 |

All 925 Jest tests passed and TypeScript type checking passed on the tested commit.

## Findings

- **A-03.** Default smart crop removed the ID text. [#57](https://github.com/dork7/cardholder/issues/57)
- **A-07.** The tag editor silently shortened a long tag. [#59](https://github.com/dork7/cardholder/issues/59)
- **A-08.** The form accepted a ninth tag and only flagged it on save. [#60](https://github.com/dork7/cardholder/issues/60)
- **A-14.** A Fabric view-mount error appeared after save. The document was present after relaunch. [#61](https://github.com/dork7/cardholder/issues/61)
- **A-15.** The blurry photo saved without a quality warning. [#55](https://github.com/dork7/cardholder/issues/55#issuecomment-7019839802)
- **H-02.** The Stack tip dismiss action was covered by the floating Add button. [#62](https://github.com/dork7/cardholder/issues/62)
- **H-17.** Batch Undo restored only one of two documents. The remaining document was recovered through Recently deleted. [#63](https://github.com/dork7/cardholder/issues/63)
- The edit sheet dismissed and lost a draft despite choosing **Keep editing**. [#58](https://github.com/dork7/cardholder/issues/58)
- Earlier missed taps on the Add button and Notes tab were added to the existing issue. [#47](https://github.com/dork7/cardholder/issues/47#issuecomment-7018580893)

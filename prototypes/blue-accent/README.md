# Blue accent library prototype

Throwaway Doc Keeper study based on the two supplied references. Showcase follows the blue favorites/recent layout. Folders makes the horizontally scrollable, overlapping space cards the main feature, in lilac, sage, sand, and blue. Every space contains documents and notes.

Run `npm run prototypes` from the repository root, then open [the prototype](http://127.0.0.1:4178/prototypes/blue-accent/?variant=showcase). The URL also accepts `?variant=folders`, `?variant=library`, and `?variant=timeline`. Use the floating arrows or keyboard left/right arrows to switch. The selected tab is shareable through `?tab=Notes` or `?tab=Spaces`.

Use pin icons on documents and notes. Favorites shows pinned documents only. Tap a space card to see its documents and notes together. Notes can be searched, created, edited, pinned, and deleted; new and edited notes can be assigned to a space. Documents and notes open in full-screen views. The + button adds a fictional sample document or a new note. The prototype has no storage, native integrations, or production app imports. All changes reset on reload.
